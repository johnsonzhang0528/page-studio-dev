# Architecture Decision Records

Create one concise decision record per material decision family. New technical decisions remain `draft` while architecture is being developed and become immutable only after Architecture Gate passes. Consolidate related backup, export, or security sub-decisions when one ADR can express the complete trade-off. Deployment parameters belong in `.ai/RELEASE_RISKS.json`, not separate ADRs. Git owns revision history; do not append per-run audit narratives here.
