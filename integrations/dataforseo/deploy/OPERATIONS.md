# DataForSEO 安全上線與復原手冊

## 現況

此目錄已整合至通過重構與 soak 的隔離候選分支，但仍只是停用狀態的部署範本，不得直接複製後啟用。預設網路開關為 0，且缺少人工建立的 enable marker 時服務不會啟動。

程式整合不等於付費流量授權；Sandbox 小額測試、正式部署與啟用必須各自取得操作者明確核准。

## 上線必要條件

1. page-studio-dev 重構與 soak 驗收完成。
2. Billing Gateway adapter 契約凍結。
3. Oracle Linux 隔離測試全部通過。
4. 價格快照重新人工核對且未過期。
5. 單次、專案每日、全域每日與全域每月上限經操作者簽核。
6. Sandbox 小額測試通過，且帳務金額一致。
7. 備份、復原、告警及緊急停用演練通過。

## 緊急停止

移除 enable marker、停止專用服務並封鎖其 outbound；保留帳本、lock、暫存檔及日誌作為證據。不得刪除帳本、不得自動重送 UNKNOWN_HOLD 請求。

## 鎖逾時

先確認沒有存活的帳本寫入程序，再封存 lock 檔與服務日誌。只有人工判定 owner 已死亡且帳本校驗通過後，才可移走 lock。不可讓程式依時間自動偷鎖。

## 帳本損毀

立即保持停用。封存損毀帳本與所有暫存檔，從已驗證備份還原至新路徑，再與 DataForSEO 帳務記錄人工對帳。對帳完成前不得重新開放付費請求。

## 回滾

回滾只切回 provider disabled 與舊版 adapter；帳本格式不可降版覆寫。保留所有已核發 lease，避免舊請求被當成新請求重送。
